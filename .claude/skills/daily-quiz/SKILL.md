# 毎日一問一答クイズ

DB設計・SQL・Webアプリケーション開発の3分野から各3問、マークダウン形式で出題する。

## 引数の処理

`$ARGUMENTS` が空 → 問題を出題する
`$ARGUMENTS` に「答え」「answer」「回答」などが含まれる → 解答と解説を表示する

## 出題フォーマット

```
## 本日の一問一答（YYYY-MM-DD）

---

### DB設計

**Q1.** （問題文）

**Q2.** （問題文）

**Q3.** （問題文）

---

### SQL

**Q1.** （問題文）

**Q2.** （問題文）

**Q3.** （問題文）

---

### Webアプリケーション開発

**Q1.** （問題文）

**Q2.** （問題文）

**Q3.** （問題文）

---

答え合わせは `/daily-quiz 答え` で確認できます。
```

## 問題の質

- 暗記ではなく理解を問う問題を選ぶ
- 実務でよく直面するシナリオを題材にする
- SQLは実際のクエリを含めると良い
- 毎回異なるテーマ・観点から出題する（前回と被らないよう意識する）

## 解答フォーマット（答え合わせ時）

出題した各問に対し、以下の形式で解答と解説を示す：

```
# daily-quiz Answer（YYYY-MM-DD）

## DB設計

**Q1.** （再掲）
**A1.** （解答）
> 解説: （なぜそうなるか、実務での注意点など）

（Q2, Q3も同様）

## SQL

（Q1〜Q3）

## Webアプリケーション開発

（Q1〜Q3）
```

## ファイル保存（答え合わせ時）

解答と解説を生成した後、必ず以下のパスに保存する：

```
Ideas/daily/daily-quiz-Answer/YYYYMMDD-answer.md
```

- `YYYYMMDD` は実行日の日付（例: `20260320`）
- Writeツールを使ってファイルを作成する
- 保存後に「`Ideas/daily/daily-quiz-Answer/YYYYMMDD-answer.md` に保存しました」と報告する
